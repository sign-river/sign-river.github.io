## 下载工具

从 [GitHub Releases](https://github.com/sign-river/Stellaris-DLC-Helper/releases/latest) 下载最新版本，并解压到方便找到的位置。

<a href="/p/stellaris-dlc-helper/images/2026-02-13-16-58-48.png" target="_blank">
  <img
    src="/p/stellaris-dlc-helper/images/2026-02-13-16-58-48.png"
    alt="工具主界面"
    style="max-width: 100%; width: 1000px;"
  />
</a>

## 第一次运行

双击 `Stellaris_DLC_Helper.exe`。程序会检查更新并显示公告；确认后，选择或确认自动识别到的游戏安装目录。

<a href="/p/stellaris-dlc-helper/images/2026-02-13-17-03-52.png" target="_blank">
  <img
    src="/p/stellaris-dlc-helper/images/2026-02-13-17-03-52.png"
    alt="启动后的更新提示"
    style="max-width: 100%; width: 1000px;"
  />
</a>

如果没有自动识别到目录，可通过“浏览”手动选择。所选目录应包含 `stellaris.exe`。

<a href="/p/stellaris-dlc-helper/images/2026-02-13-17-06-52.png" target="_blank">
  <img
    src="/p/stellaris-dlc-helper/images/2026-02-13-17-06-52.png"
    alt="选择安装目录"
    style="max-width: 100%; width: 1000px;"
  />
</a>

## 完成操作

确认目录无误后，按界面提示完成操作。进度和结果会显示在程序中；完成后通过 Steam 启动游戏验证。

<a href="/p/stellaris-dlc-helper/images/2026-02-13-17-09-52.png" target="_blank">
  <img
    src="/p/stellaris-dlc-helper/images/2026-02-13-17-09-52.png"
    alt="操作进度界面"
    style="max-width: 100%; width: 1000px;"
  />
</a>

> 仅支持 Windows。使用前建议备份存档和重要的游戏文件。
