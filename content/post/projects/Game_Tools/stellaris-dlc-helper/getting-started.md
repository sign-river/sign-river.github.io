## 1. 下载并解压

从 [GitHub Releases](https://github.com/sign-river/Stellaris-DLC-Helper/releases/latest) 下载最新版本，解压到便于访问的位置。

<a href="/p/stellaris-dlc-helper/images/2026-08-28-02-45-18.png" target="_blank"> <img src="/p/stellaris-dlc-helper/images/2026-08-28-02-45-18.png" alt="image" style="max-width: 100%; width: 1000px;"/> </a>

## 2. 首次运行

双击 `Stellaris_DLC_Helper.exe` 启动程序。首次打开时，程序会检查更新、显示公告，并尝试自动识别游戏安装目录。

<a href="/p/stellaris-dlc-helper/images/2026-08-28-02-46-03.png" target="_blank"> <img src="/p/stellaris-dlc-helper/images/2026-08-28-02-46-03.png" alt="image" style="max-width: 100%; width: 1000px;"/> </a>

<a href="/p/stellaris-dlc-helper/images/2026-08-28-02-47-45.png" target="_blank"> <img src="/p/stellaris-dlc-helper/images/2026-08-28-02-47-45.png" alt="image" style="max-width: 70%; width: 1000px;"/> </a>

如果未能自动识别目录，请点击 **浏览** 手动选择游戏目录。所选目录中应包含 `stellaris.exe`。

<a href="/p/stellaris-dlc-helper/images/2026-08-28-02-52-26.png" target="_blank"> <img src="/p/stellaris-dlc-helper/images/2026-08-28-02-52-26.png" alt="image" style="max-width: 70%; width: 1000px;"/> </a>

## 3. 执行解锁

确认游戏目录无误后，点击 **一键解锁**。程序会在界面中显示执行进度和结果。

<a href="/p/stellaris-dlc-helper/images/2026-08-28-02-53-14.png" target="_blank"> <img src="/p/stellaris-dlc-helper/images/2026-08-28-02-53-14.png" alt="image" style="max-width: 70%; width: 1000px;"/> </a>

操作完成后，可通过 Steam 启动游戏并查看效果。

<a href="/p/stellaris-dlc-helper/images/2026-08-28-02-56-25.png" target="_blank"> <img src="/p/stellaris-dlc-helper/images/2026-08-28-02-56-25.png" alt="image" style="max-width: 70%; width: 1000px;"/> </a>

当 DLC 图标下方均显示绿色 ✅️ 时，表示本次操作已完成。

> 仅支持 Windows。使用前建议备份存档和重要的游戏文件。
