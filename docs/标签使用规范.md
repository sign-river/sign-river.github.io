# 博客标签使用规范

本文档记录博客文章 `tags` 字段的规范用法，目的是保持标签池整洁、语义清晰、覆盖全面。

---

## 一、核心原则

1. **不造冗余**：同一含义只用一个标签，不允许近义词并存（如 `开发工具` 和 `开发者工具`）
2. **不吝啬**：只要某个标签能准确描述文章的关键点，就应当打上，不要为了减少数量而省略
3. **用具体名词**：优先使用工具名、技术名等具体词（如 `Hugo`、`Git`），而非泛化描述（如 `工具`）

## 四、新增标签的判断标准

满足以下任一条件，可以新增标签：

- 这个概念在多篇文章中都会用到
- 这是一个具体的工具名 / 技术名，未来可能有更多相关文章
- 去掉这个标签后，读者通过标签搜索会找不到这篇文章

**不建议新增**：

- 意义过于宽泛，如 `技术`、`分享`、`推荐`、`好用`
- 与已有标签完全同义的近义词
