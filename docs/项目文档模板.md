# 项目文档模板

项目类内容统一采用多页文档格式。显示效果由 `layouts/project-docs/` 提供，包含项目内目录、当前页高亮和上一页/下一页导航。

## 新建项目

1. 复制 `templates/project-docs/` 到 `content/post/projects/<项目分类>/<项目目录>/`。
2. 将所有 `project-slug` 改为唯一的小写英文 slug。
3. 将 `draft: true` 改为 `draft: false` 后发布。
4. 在 `content/page/projects/index.md` 的 `projects` 列表中补充项目卡片，并将 `website` 指向 `/p/project-slug/`。

目录结构如下：

```text
content/post/projects/<项目分类>/<项目目录>/
├── _index.md          # 项目首页与项目信息
├── getting-started.md # 快速开始
├── daily-use.md       # 日常使用
├── faq.md             # 常见问题
└── images/            # 项目图片
```

## 必填规范

- 项目首页必须使用 `type: "project-docs"`、`weight: 1`、固定的 `url: "/p/<slug>/"`，并用 `redirect_to: "/p/<slug>/getting-started/"` 直接跳转到快速开始；不要在首页保留正文。
- 子页面必须使用 `type: "project-docs"`，URL 固定为 `"/p/<slug>/<页面名>/"`。
- 子页通过 `weight` 排序：快速开始为 `10`，日常使用为 `20`，常见问题为 `30`。新页面从 `40` 起按 `10` 递增。
- 所有项目页面分类使用 `"项目"`；标签按 [分类标签规范](分类标签规范.md) 填写。
- 图片放入同级 `images/`，并使用相对路径引用，例如 `images/overview.png`。

## 可选章节

按项目需要新增以下页面，并设置连续的 `weight`：

- `configuration.md`：配置参考
- `api-reference.md`：接口或命令参考
- `deployment.md`：部署与运维
- `changelog.md`：版本更新记录

不要为一次性短说明创建独立页面；内容足够构成独立任务或参考主题时再拆分。
