# 博客配置说明

## 📋 快速配置指南

所有博客的可调整参数都集中在 `config/_default/params.toml` 文件的 **[blog_params]** 部分，修改后 Hugo 服务器会自动检测并重新加载，**无需手动重启**！

## ⚙️ 配置项说明

### 文章卡片显示 (`[article_card]`)

```toml
[article_card]
max_tags = 3  # 左上角标签最大显示数量
```

**作用**：控制文章卡片左上角显示的标签数量（分类 + tags 总共）

- `max_tags = 3`：最多显示 3 个标签
- `max_tags = 5`：最多显示 5 个标签
- 如果文章标签总数 ≤ 设定值，则全部显示

**效果**：

- 1 个分类 + 2 个 tags = 3 个标签 ✅
- 1 个分类 + 5 个 tags = 显示 1 个分类 + 前 2 个 tags（共 3 个）✅

---

### 首页文章列表 (`[blog_params.homepage]`)

```toml
[blog_params.homepage]
posts_per_page = 10  # 每页显示的文章数量
show_summary = true  # 是否显示文章摘要
```

**作用**：

- `posts_per_page`：控制首页和归档页面每页显示多少篇文章
- `show_summary`：是否在文章列表中显示摘要

---

### 侧边栏设置 (`[blog_params.sidebar]`)

```toml
[blog_params.sidebar]
categories_limit = 10  # 显示的分类数量限制
tags_limit = 15       # 显示的标签数量限制
```

**作用**：

- `categories_limit`：左侧边栏"分类"小工具显示的分类数量
- `tags_limit`：左侧边栏"标签云"小工具显示的标签数量

---

### 文章页面设置 (`[blog_params.article_page]`)

```toml
[blog_params.article_page]
show_reading_time = true      # 是否显示阅读时间
show_publish_date = true      # 是否显示发布日期
related_posts_limit = 5       # 相关文章显示数量
```

**作用**：

- `show_reading_time`：在文章底部显示阅读时间
- `show_publish_date`：在文章底部显示发布日期
- `related_posts_limit`：文章底部显示的相关文章数量

---

## 🔧 使用方法

### 1. 修改配置

打开 `config/_default/params.toml` 文件，找到 `[blog_params]` 部分，修改对应的值：

```toml
# 想把标签数量从 3 改成 5？
[blog_params.article_card]
max_tags = 5  # 改这里！

# 想调整首页文章数量？
[blog_params.homepage]
posts_per_page = 15  # 改这里！
```

### 2. 保存生效

Hugo 服务器会自动检测配置文件变化并重新加载，**无需手动重启**！

### 3. 查看效果

刷新浏览器即可看到修改后的效果。

## 📝 配置原则

✅ **推荐这样做**：

- 所有自定义参数都放在 `blog_params.toml` 中
- 使用有意义的变量名
- 添加注释说明每个参数的作用
- 为所有配置项提供默认值

❌ **不推荐这样做**：

- 在模板文件中硬编码数字（如 `max_tags := 3`）
- 分散配置到多个文件
- 不写注释，以后自己都看不懂

## 🎯 常用配置示例

### 示例 1：简洁风格（少标签）

```toml
[article_card]
max_tags = 2  # 只显示最重要的 2 个标签

[homepage]
posts_per_page = 5  # 首页只显示 5 篇文章
```

### 示例 2：丰富风格（多标签）

```toml
[article_card]
max_tags = 5  # 显示更多标签

[sidebar]
tags_limit = 30  # 显示更多标签云
```

### 示例 3：极简风格（隐藏部分信息）

```toml
[article_page]
show_reading_time = false  # 不显示阅读时间
show_publish_date = false  # 不显示发布日期
```

## 💡 扩展配置

如果想添加新的可配置项，可以：

1. 在 `blog_params.toml` 中添加新参数
2. 在模板中通过 `.Site.Params.blog_params.你的参数名` 访问
3. 提供合理的默认值

例如添加"是否显示文章封面"：

```toml
# 在 params.toml 的 [blog_params.article_card] 部分添加
max_tags = 5
```

```html
<!-- 在模板中使用 -->
{{- $maxTags := .Site.Params.blog_params.article_card.max_tags | default 3 -}}
```
